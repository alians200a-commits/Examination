# Examination Studio

محرّر امتحانات عربي بأسلوب قريب من Word، موجّه للمدارس العراقية، ويدعم:

- **واجهة عربية Mobile-first** تناسب الموبايل أولًا ثم التابلت ثم الحاسوب.
- **إدخال عربي وإنكليزي** مع احترام اتجاه النص RTL / LTR.
- **معادلات إنكليزية** عبر MathLive / LaTeX.
- **معادلات عربية منفصلة** بصيغة مخصصة للكتابة الرياضية العربية.
- **تصدير PDF فقط** عبر الطباعة المباشرة.
- **رفع شعار داخل الهيدر** مع ضبط تلقائي وإمكانية التحريك وتعديل الحجم.
- **ثيمات لونية مدروسة** للطباعة والعرض.
- **قوالب امتحانية جاهزة** للمراحل الابتدائية والمتوسطة والإعدادية.
- **حفظ تلقائي محلي** مع إمكان تصدير / استيراد ملف JSON للمشروع.

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## ملاحظات

- التصدير الرسمي هو **PDF** فقط.
- طباعة A4 مهيأة من خلال `@media print` و `@page`.
- الواجهة صُممت لتكون مريحة على الشاشات الصغيرة قبل الكبيرة.
