# Examination Studio v0.4

برنامج لإنشاء أوراق الامتحانات العراقية. صار وضع **إدخال الأسئلة بالاستمارة** هو الأساس، وفق طريقة الفيديو المرجعي: بيانات الترويسة ← سؤال وعنوانه ودرجته ← أفرع تُضاف وتُحذف ← معاينة A4 ← PDF. يبقى محرّر Word-like خيارًا منفصلًا عند الحاجة إلى تنسيق حر.

## المميزات

- استمارة مستقلة لكل سؤال: عنوان، نص، درجة، أفرع غير محدودة عمليًا، حذف، نسخ، تغيير الترتيب وإضافة أسئلة جديدة.
- بيانات الامتحان أعلى الاستمارة والورقة: المدرسة، الصف، المادة، العام الدراسي، دور الامتحان، المدة والملاحظات.
- معاينة ورقة A4 حقيقية مع التكبير والتصغير. في الموبايل تبويب للكتابة وتبويب للمعاينة؛ في الحاسوب كلاهما بجانب الآخر.
- معادلات عربية منفصلة عن الإنكليزية: الأرقام ٠–٩ حتى إن كُتبت بأرقام لاتينية، وكسور عمودية وجذور وأسُس وقيم مطلقة وعلامات العلاقات والتكامل والجمع المبسّط، تُنسّق عبر KaTeX بعد تحليل الصياغة العربية.
- نافذة المعادلة العربية تضم لوحة أرقام ورموز عربية وأزرار قوالب للكسر والجذر والأسّ، مع معاينة وتحذير عند وجود تركيب غير مدعوم.
- معادلات إنكليزية MathLive / LaTeX كما هي، مستقلة عن المعادلات العربية.
- شعار قابل للسحب والتحجيم في ترويسة الورقة، خمسة ثيمات، قوالب للمراحل الابتدائية والمتوسطة والإعدادية.
- حفظ تلقائي محلي ونسخ احتياطية JSON تدعم الوضعين. يُحتفَظ بمستندات v0.3 القديمة في المحرّر الحر عند الاستيراد.
- التصدير PDF فقط عبر المتصفح، بخطوط عربية مضمّنة دون اعتماد على اتصال الإنترنت.

## التشغيل

```bash
npm ci
npm run test:math
npm run dev
```

## البناء

```bash
npm run build
```

## ملاحظات فنية

- معادلات العربية تدعم التعابير الجبرية الأساسية المتداخلة؛ المصفوفات المعقدة والمحاذاة متعددة الأسطر تحتاج محرر LaTeX الإنكليزي حاليًا.
- التصدير يعتمد على `window.print()`، وقد لا يعمل داخل بعض WebView؛ افتح المشروع في Chrome أو Edge عند الحاجة.
- الصور المعقدة والأسئلة متعددة الصفحات قد تحتاج مراجعة فواصل الصفحات في الطباعة، لأن خطوط التقسيم في المعاينة تقريبية.
- المشروع ليس نسخة من البرنامج المعروض في الفيديو؛ يعيد تنفيذ سير عمله المطلوب مع الحفاظ على محرر المستندات الموجود.
