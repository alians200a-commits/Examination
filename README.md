# استوديو الامتحانات — Examination Studio

برنامج ويب عربي مفتوح المصدر لإعداد أوراق الامتحانات وطباعتها، مستوحى من تنسيق الامتحانات العراقية، بواجهة شريط أدوات قريبة من Microsoft Word.

## الوظائف الموجودة في النسخة الأولية

- واجهة عربية RTL، مع تحكم باتجاه الفقرة RTL/LTR ونصوص مختلطة بالعربية والإنكليزية.
- تحرير غني بواسطة **Tiptap**: عناوين، خط، حجم، لون، محاذاة، جداول، قوائم، تراجع وإعادة.
- إنشاء معادلات وتعديلها عبر **MathLive**، وعرضها بواسطة **KaTeX**؛ تُحفظ بصيغة LaTeX في ملف المشروع.
- إدراج قوالب تعريفات، املأ الفراغات، اختيار متعدد، سؤال مقالي، وعدّد فقط.
- ترويسة الامتحان القابلة للتعديل، وأربعة ثيمات ألوان، ومعاينة A4.
- تصدير PNG بدقة تقارب 300 DPI، أو PDF من نافذة الطباعة.
- ثيم فيديو بحركة هادئة، وتصدير فيديو **WebM** مدته 8 ثوانٍ، بنسبة 9:16 أو 16:9، من ورقة الامتحان الفعلية. يستخدم MediaRecorder على Chrome أو Edge؛ لا يتطلب خدمة فيديو مدفوعة.
- حفظ تلقائي على الجهاز، وتصدير/استيراد ملف JSON قابل للاستئناف.

## تشغيل المشروع

المتطلبات: Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

افتح العنوان الذي يظهر في الطرفية (عادة `http://localhost:5173`). لإنشاء نسخة النشر:

```bash
npm run build
npm run preview
```

يمكن نشر مجلد `dist/` في استضافة ملفات ثابتة. `vite.config.ts` يستخدم `base: './'` ليتوافق مع المسارات الفرعية.

## ملاحظات فنية مهمة

1. **الترقيم التلقائي للصفحات:** معاينة التحرير تعرض ورقة A4 قابلة للتمدد، لكن تقسيم الجداول والفقرات الطويلة على صفحات A4 منفصلة ليس مكتملاً في هذه النسخة. الطباعة تعتمد تقسيم متصفح Chrome/Edge؛ افحص معاينة الطباعة عند تجاوز صفحة واحدة.
2. **المعادلات:** العرض بجودة تنضيد رياضي عبر KaTeX، والتحرير عبر MathLive؛ هذه ليست ملفات MathType OLE ولا يوجد حتى الآن استيراد MathType أو DOCX/OMML.
3. **الفيديو:** التصدير WebM، وليس MP4، بدون تعليق صوتي؛ نافذة المعاينة هي تصور بصري، بينما ملف الفيديو يستعمل لقطة حقيقية من ورقة المستند عند التصدير.
4. **الخصوصية:** التخزين محلي في `localStorage`. يجب حفظ ملف JSON دوريًا؛ لا يوجد حساب سحابي أو مزامنة بين الأجهزة.
5. **الخطوط:** خطوط Cairo وNoto Naskh Arabic تُحمّل من Google Fonts عند توفر الإنترنت، مع خطوط احتياطية محلية. تأكد من تحميل الخط قبل تصدير PNG.
6. **التنسيق:** هذه نسخة تأسيسية للتطوير وليست محرّر Word كاملًا؛ قوالب الأسئلة نصية ويمكن تخصيصها بحرية.

## مصادر المشاريع والتراخيص

- [Tiptap](https://github.com/ueberdosis/tiptap) — محرر MIT.
- [MathLive](https://github.com/arnog/mathlive) — مكوّن معادلات MIT.
- [KaTeX](https://github.com/KaTeX/KaTeX) — عرض المعادلات MIT.
- [Lucide](https://github.com/lucide-icons/lucide) — أيقونات ISC.
- [html-to-image](https://github.com/bubkoo/html-to-image) — تصدير DOM إلى صورة، MIT.

الكود الخاص بهذا المستودع ليس نسخًا لمشروع pagination غير مدقق الترخيص. يمكن إضافة نظام صفحات متقدم بعد اختبار ملاءمته ودعم العربية والجداول.
