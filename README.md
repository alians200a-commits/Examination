# Examination Studio 0.5 — استوديو الامتحانات

تطبيق عربي لإنشاء أسئلة الامتحانات العراقية من خلال استمارة واحدة تشمل البيانات، الأسئلة، الأفرع، الصور، المعادلات والمعاينة.

## الجديد

- اختيار **المرحلة ← الصف ← المادة**، مع تحديد عنوان الامتحان والسنة الدراسية 2027-2026 (قابلة للتعديل) والتاريخ الهجري الاختياري.
- مرحلة الرابع الابتدائي محددة بالعربية والرياضيات حسب متطلبات المشروع؛ الخامس والسادس تعرض بقية المواد. المتوسطة والإعدادية تعرض المواد بحسب الصف والمسار العلمي/الأدبي، مع توثيق عام من [فهرس الكتب العراقية](https://iraqedu.net/الكتب-المنهجية/).
- الترقيم العربي تلقائيًا لكل المواد الابتدائية باستثناء الإنكليزية. في المتوسطة والإعدادية: الإسلامية والعربية والاجتماعيات والتاريخ والجغرافية والاقتصاد بالعربي، والبقية بالإنكليزي، مع تبديل يدوي لترقيم الأسئلة والأفرع.
- دعم أفرع عربية/إنكليزية وقوائم متداخلة ودرجات اختيارية لكل فرع.
- إضافة صور للسؤال أو للفرع، مع التحكم في العرض والمحاذاة وتقليل حجم الملفات قبل الحفظ.
- خطوط Noto Naskh Arabic وCairo مضمنة محليًا، أو رفع خط إضافي خاص بالمستخدم.
- محرّر معادلات عربية بكسور **عمودية** وجذور وأسُس ورموز المقارنة؛ `قسمة(١٢،٣،٤)` ترسم القسمة الطويلة. محرر منفصل للمعادلات الإنكليزية بـMathLive، و`longdiv(12,3,4)` للقسمة الطويلة.
- صفحات A4 مستقلة: إضافة صفحة وتوزيع الأسئلة بينها. **الترويسة بالصفحة الأولى فقط، و«اقلب الصفحة» بنهاية كل صفحة غير أخيرة، والتذييل في الصفحة الأخيرة فقط.**
- المعاينة والطباعة تستخدمان **نفس عناصر A4**. إن تجاوز محتوى صفحة المساحة المتاحة، يظهر تحذير ويمنع زر PDF حتى يُصحَّح التوزيع، بدل إنشاء صفحة إضافية عشوائيًا.
- التحرير الحر داخل آخر صفحة اختياري وفي نفس مستند الامتحان؛ لا توجد واجهتان منفصلتان لإدخال الأسئلة.
- التصدير PDF من نافذة الطباعة في Chrome/Edge (اختر A4، 100%، أوقف رؤوس وتذييلات المتصفح إن ظهرت). الحفظ JSON اختياري للاحتفاظ بالمشروع قابلًا للتحرير.

## التشغيل

```bash
npm ci
npm run dev
```

## الاختبارات

```bash
npm run test:math
npm run build
npm run test:print
```

`test:print` يحتاج Chrome/Chromium و`pdfinfo`، ويتحقق من تطابق عدد صفحات A4 مع عدد صفحات PDF لملف مكوّن من صفحة ثم صفحتين.
