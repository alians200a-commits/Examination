# Examination Studio

محرّر امتحانات عربي للمدارس العراقية. تُعرض الورقة بحجم **A4 حقيقي** على كل الشاشات (تُصغَّر لتناسب الهاتف كما في معاينة الطباعة)، فما تراه هو ما يُطبع في PDF.

## المزايا

- ورقة A4 ثابتة مع تكبير/تصغير وخطوط تقريبية لحدود الصفحات.
- كتابة عربية وإنكليزية مع RTL / LTR، وخطوط مضمّنة تعمل بدون إنترنت.
- معادلات LaTeX (MathLive) ومعادلات عربية بمحرر مستقل؛ النقر على المعادلة يفتح تعديلها.
- جداول (إضافة/حذف صفوف وأعمدة) وفاصل صفحة وقوالب أسئلة جاهزة.
- شعار قابل للسحب والتحجيم في الترويسة، ويُضغط تلقائيًا قبل الحفظ.
- خمسة ثيمات ونماذج امتحانية للمراحل الابتدائية والمتوسطة والإعدادية.
- حفظ تلقائي محلي + حفظ/فتح المشروع كملف JSON.
- تصدير PDF عبر الطباعة (`@page` بهامش 12mm يطابق المعاينة).

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## البنية

```
src/
  App.tsx                  الشريط العلوي والأدوات وربط الأجزاء
  components/Stage.tsx     عرض الورقة A4 والتكبير وحدود الصفحات
  components/ExamSheet.tsx الترويسة والشعار ومحتوى الورقة
  components/SettingsPanel.tsx  لوحة البيانات والشعار والثيم والنماذج
  components/Dialogs.tsx   نوافذ المعادلات والتأكيد
  MathSupport.tsx          عقد المعادلات (LaTeX / عربية)
  extensions.ts            الاتجاه، الخط، فاصل الصفحة
  storage.ts, image.ts     الحفظ مع التحقق، وضغط الشعار
  data.ts                  القوالب والثيمات والقيم الافتراضية
```

## ملاحظات

- الطباعة تعتمد على `window.print()`؛ قد لا تعمل داخل بعض تطبيقات WebView، وفي هذه الحالة استخدم المتصفح.
- تغيير عرض أعمدة الجدول بالسحب معطّل لأنه يعمل معكوسًا في الاتجاه RTL.
